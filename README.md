# 🛠️ MotoGo Backend

Este es el backend de **MotoGo**, una aplicación móvil para motociclistas que necesitan encontrar servicios técnicos o venta de consumibles de forma confiable, según el tipo de motocicleta y la ubicación del usuario.

Este backend está desarrollado en **Go** con una arquitectura **hexagonal (puertos y adaptadores)** que facilita la escalabilidad, la organización del código y las pruebas.
